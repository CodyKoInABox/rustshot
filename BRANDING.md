# RustShot brand assets

The public product name is **RustShot**. The lowercase `rustshot` form is reserved for executable,
package, and repository identifiers where lowercase naming is conventional or required.

## Asset catalog

| Asset | Purpose |
| --- | --- |
| `assets/rustshot-logo.png` | Transparent full logo and wordmark for documentation and release pages |
| `assets/rustshot-icon.png` | Transparent standalone mark for square placements |
| `resources/rustshot.ico` | Multi-resolution Windows executable icon from 16 through 256 pixels |
| `resources/rustshot-tray.png` | Optimized 64-pixel runtime tray icon |

The logo retains its original aspect ratio, transparency, colors, and arrangement. The full
wordmark is used where the product name needs to be visible; the standalone mark is used for
compact square placements. The raster artwork supplied for version 1.0 is the current source for
the derived Windows assets.
