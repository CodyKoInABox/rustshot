# RustShot brand assets

The public product name is **RustShot**. The lowercase `rustshot` form is reserved for executable,
package, and repository identifiers where lowercase naming is conventional or required.

## Asset catalog

| Asset | Purpose |
| --- | --- |
| `assets/rustshot-logo-light.png` | Dark-backed full logo and wordmark for white or light pages |
| `assets/rustshot-logo.png` | Transparent full logo and wordmark for dark surfaces |
| `assets/rustshot-icon.png` | Transparent standalone mark for square placements |
| `resources/rustshot.ico` | Multi-resolution Windows executable icon from 16 through 256 pixels |
| `resources/rustshot-tray.png` | Optimized 64-pixel runtime tray icon |

The full wordmark is used where the product name needs to be visible; the standalone mark is used
for compact square placements. The dark-backed variant keeps the white lettering visible on GitHub
and other white interfaces. The raster artwork supplied for version 1.0 is the current source for
the derived Windows assets.
