## Interpretation notes

- Activation latency is the cleanest comparable capture-speed metric: hotkey injection until the overlay becomes visible.
- Workflow latency includes identical fixed overlay, selection, and mouse-drag delays used by the automation.
- Lightshot is copied through its visible toolbar button because its keyboard copy handler does not reliably accept synthetic input.
- Lower latency and resource values are better. Executable size is reported separately and is not a speed measurement.
- Results describe this machine and run configuration; compare several complete runs before drawing broader conclusions.
